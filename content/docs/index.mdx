This is a personal playbook of patterns and notes on building AI agents,
retrieval-augmented generation (RAG) systems, and the infrastructure behind them.

- [Workflows & Agents](/docs/workflows-and-agents/overview) — tool/function-calling design, human-in-the-loop approval, memory, and agent/workflow patterns
- [MCP](/docs/mcp/overview) — the Model Context Protocol: architecture, building servers and clients, connecting to servers, authorization and security, and debugging
- [Observability](/docs/observability/overview) — tracing, experiments, evals, monitoring, prompts, and AI gateway for LLM systems
- [RAG](/docs/rag/overview) — retrieval-augmented generation patterns, from basic retrieval through adaptive routing
- [Data Synchronization](/docs/data-synchronization/overview) — keeping a vector database current against changing sources: change data capture, batch orchestration, incremental sync/dedup, and managed ELT
- [Vector Management](/docs/vector-management/database) — collections, schemas, ingestion, indexes, search, function/model inference, storage optimization, and snapshots
